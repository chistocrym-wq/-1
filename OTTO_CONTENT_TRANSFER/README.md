# OTTO — CONTENT TRANSFER PACKAGE

Этот каталог предназначен для переноса содержательной части тренажёра A1 в другой проект.

## ВАЖНО

- LESEN / Lesen полностью исключён из переноса.
- Не переносить UI, CSS, React-компоненты, routing, deployment и дизайн.
- Не переносить `.env`, API keys, токены, пароли или Vercel secrets.
- Содержимое заданий переносить как данные, а не переписывать вручную.
- AI API подключается уже в новом проекте через его собственный server-side secret.

## Что переносить

- `src/data/listening.ts`

Также есть более ранний/упрощённый источник `src/data/schreibenTeil1.ts`; при интеграции использовать `schreibenTeil1Imported.ts` как основной набор.

### SPRECHEN
Источник:

Актуальная логика Teil 1 использует пункты:

- Alter?
- Land?
- Wohnort?
- Beruf?
- Sprachen?
- Hobby?

## Правила проверки SCHREIBEN Teil 2

AI-проверка использует модель `gpt-5` на сервере.

Правила:
- каждый обязательный пункт: 3 / 1.5 / 0;
- communicative design: 1 / 0.5 / 0;
- итог = набранные баллы / максимум × 100;
- языковые ошибки не снижают баллы за содержание, если смысл понятен и пункт выполнен;
- естественные A1-формулировки принимаются, дословное совпадение не требуется;
- минимум 30 слов;
- максимум 6 реальных исправлений;
- `original` в исправлении должен быть дословной цитатой ученика;
- для пропущенного пункта использовать `Не выполнено`;
- объяснение: термин немецкой грамматики + простое объяснение по-русски;
- feedback: короткий, доброжелательный, сначала немецкий, затем русский.

Полная server-side реализация/эталон промпта находится в:
- `api/check-schreiben.js`

При переносе можно взять из него только prompt/schema/правила проверки. Сам API handler не является обязательной частью content package.

## Правила проверки SPRECHEN

Архитектура:
1. браузер записывает голос;
2. аудио отправляется на сервер после завершения записи;
3. speech-to-text получает техническую транскрипцию;
4. отдельная дешёвая модель проверяет покрытие каждого пункта.

Модели текущей реализации:
- STT: `gpt-4o-mini-transcribe`, fallback `whisper-1`;
- evaluation: `gpt-4o-mini`.

Важно: это не настоящий фонетический экзамен. Текущая система оценивает, была ли требуемая информация сказана, и отдельно показывает ориентир понятности записи по speech-recognition confidence. Орфография, написание и письменные окончания НЕ проверяются.

Полный эталон prompt/schema находится в:
- `api/check-sprechen.js`

## Формат данных для нового проекта

Рекомендуется сохранить данные в отдельных JSON/TS/DB-коллекциях с полями:

`id`, `module`, `part`, `type`, `difficulty`, `title`, `situation`, `instruction`, `points`, `fields`, `options`, `correctAnswer`, `explanation`, `audio`, `topic`, `grammarFocus`, `vocabulary`.

Для HÖREN обязательно сохранять связь задания с аудиофайлом.

Для SCHREIBEN Teil 1 сохранять поля формы и правильные ответы.

Для SCHREIBEN Teil 2 сохранять ситуацию и все три обязательных пункта.

Для SPRECHEN сохранять task + массив обязательных пунктов.

## Секреты

В этот пакет НЕ должны попадать:
- `OPENAI_API_KEY`;
- `VERCEL_*` secrets;
- Telegram tokens;
- любые `.env` со значениями;
- cookies/session tokens;
- passwords.

В новом проекте ключ OpenAI должен быть создан и подключён отдельно на сервере.

## Не переносить

`src/components/`, CSS, App routing, Dashboard, UI, hooks состояния, дизайн, шрифты и прочий presentation layer — это не часть данного content package.

`src/data/lesen/` и `src/data/reading.ts` — НЕ ПЕРЕНОСИТЬ.
